PROYECTO: Inventory Farmasi
TABLA: items (Inventory)

---------------------------------------------------------------------
FIELD (Column)  | DATA TYPE     | DESCRIPTION
---------------------------------------------------------------------
id              | SERIAL (Int)  | Unique identifier (Primary Key)
name            | VARCHAR(100)  | Product name (E.g: Shampoo)
quantity        | INTEGER       | Available quantity in stock
description     | TEXT          | Product details
price           | DECIMAL       | Sale price (Optional)
---------------------------------------------------------------------

EXAMPLE REAL DATA (JSON):
{
  "id": 1,
  "name": "Tea Tree Soap",
  "quantity": 25,
  "description": "Natural soap for oil control.",
  "price": 4500
}
